# VidExplorer
视频库管理软件

## 功能
* **视频合集**：创建、打开、关闭合集；每个合集包含一个根文件夹及其所有子文件夹中的视频。
* **最近合集**：初始界面显示最近打开的5个合集，双击即可打开。
* **加载视频列表**：打开合集后，扫描目录下所有视频文件，以网格卡片显示。
* **显示缩略图**：从视频中提取一帧，如果没有则显示默认图标。
* **播放视频**：点击卡片，调用系统默认播放器。
* **视频管理**：排序、移动、重命名、删除视频。
* **文件夹管理**：打开、重命名、批量添加标签。
* **标签系统**：为视频添加、编辑、删除标签。
* **标签管理器**：查看所有标签、重命名、删除。
* **搜索功能**：按文件名或标签搜索视频。

## 安装与运行
1.安装依赖

```shell
pip install -r requirements.txt
```

2.运行

```shell
python -m videxplorer
```

## 代码目录结构

```
VidExplorer/
    videxplorer/        # 主包目录
        __init__.py
        __main__.py     # 应用入口
        core/           # 核心业务逻辑
            library.py  # 视频库管理
            loader.py   # 视频加载器
            search.py   # 搜索引擎
        models/         # 数据模型（合集注册表、合集数据库）
        ui/             # UI 相关
        utils/          # 工具函数
    data/               # 运行时数据
        collections.db  # 合集注册表（合集名称、根文件夹、数据库路径）
        collections.sql # 合集注册表建表脚本
        videos.sql      # 合集数据库建表脚本
        film.db         # 合集"Film"的数据库
        thumbnails/     # 缩略图缓存（每个合集一个子目录）
            film/       # 合集"Film"的缩略图
    tests/              # 单元测试
    requirements.txt    # Python依赖
```

## 搜索语法

* `tag:标签名`：具有该标签的视频，可重复使用，标签名含空格时加引号（例如`tag:"xx xx"`）
* `tag:none`：没有任何标签的视频
* 其他文字：标题中包含该文字的视频

多个条件之间取交集。

例如：`tag:foo tag:bar baz`表示搜索同时具有标签"foo"和"bar"，且标题包含"baz"的视频。
