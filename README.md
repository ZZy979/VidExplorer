# VidExplorer
视频库管理软件

## 功能
* **视频合集**：创建、打开、关闭合集；每个合集包含一个根文件夹及其所有子文件夹中的视频。
* **最近合集**：初始界面显示最近打开的5个合集，双击即可打开。
* **加载视频列表**：打开合集后，扫描目录下所有视频文件，以网格卡片显示。
* **显示缩略图**：从视频中提取一帧，如果没有则显示默认图标。
* **播放视频**：点击卡片，调用系统默认播放器。
* **视频管理**：排序、移动、重命名、删除视频。
* **文件夹管理**：打开、重命名、批量添加标签。
* **标签系统**：为视频添加、编辑、删除标签。
* **标签管理器**：查看所有标签、重命名、删除。
* **搜索功能**：按文件名、标签、日期或播放次数搜索视频。

## 安装与运行
1.安装依赖

```shell
pip install -r requirements.txt
```

2.运行

```shell
python -m videxplorer
```

## 搜索语法

* 不含冒号的文字：标题中包含该文字的视频
* 含冒号的文字：`字段:表达式`，支持的字段如下

| 字段 | 说明 | 表达式 |
| --- | --- | --- |
| `tag` | 标签 | 标签名（相等匹配，不区分大小写；含空格时加引号，例如`tag:"xx xx"`；`tag:none`表示没有任何标签的视频） |
| `date` | 文件修改日期（即卡片上显示的日期） | `YYYY-MM-DD`、`>YYYY-MM-DD`、`>=YYYY-MM-DD`、`<YYYY-MM-DD`、`<=YYYY-MM-DD` |
| `play` | 播放次数 | `n`、`>n`、`>=n`、`<n`、`<=n` |

`tag`、`date`、`play` 以外的字段名会当作普通文字按标题搜索（例如`star:wars`）。

多个条件之间取交集。

例如：`tag:foo play:>0 date:>=2024-01-01 baz`表示搜索同时具有标签"foo"、播放过、修改日期不早于2024-01-01，且标题包含"baz"的视频。
